Todavía no conectaste Supabase

Este panel de admin necesita un proyecto de Supabase para guardar el menú, el horario y los pedidos.

  1. Creá un proyecto gratis en supabase.com.
  2. Abrí el archivo supabase-schema.sql de esta carpeta, pegalo en el "SQL Editor" de tu proyecto y ejecutalo.
  3. En "Authentication → Users" creá tu usuario de admin (email y contraseña).
  4. En "Project Settings → API" copiá el Project URL y la anon public key.
  5. Pegalos en este archivo (admin.html), al principio, donde dice SUPABASE_URL y SUPABASE_ANON_KEY.

Los pasos completos están en ADMIN-SETUP.md.
